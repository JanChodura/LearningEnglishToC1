## Local HTML Preview

Run `startServer.bat` from the project root to preview the generated static site from `html/`.

- Fixed port: `8000`
- Local URL: `http://localhost:8000/`

The script changes into `html/` and starts Python's built-in `http.server`.
It tries `py` first and falls back to `python`.
